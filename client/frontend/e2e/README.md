# E2E-тесты фронта (M29)

Playwright проходит пять демо-персонажей от выбора компании до итогового экрана. Каждый путь запускается
дважды, результаты обязаны совпасть между собой и с ожидаемыми значениями из `docs/test-scenarios.md`.

| Тест | Персонаж | Исход |
|---|---|---|
| TS-01 | ООО «Кофейня» | автоодобрение, выдача 2 000 000 ₽ |
| TS-02 | ИП Петров | андеррайтер, дозапрос с договором, иные условия, выдача 1 950 000 ₽ |
| TS-03 | ИП Кузнецова | иные условия от системы, выдача 1 200 000 ₽ |
| TS-04 | ООО «Техснаб» | погасил долг ФНС, автоодобрение, выдача 800 000 ₽ |
| TS-05 | ООО «Техснаб» | не погасил долг, отказ с причиной |
| TS-06 | ООО «Однодневка» | отказ по неустранимым условиям |

## Запуск

1. Поднять проект с настоящим бэкендом: в корне `docker compose up --build` (в `.env` — `VITE_USE_MOCKS=false`
   или пусто). Дождаться статуса `healthy` у всех сервисов.
2. Один раз установить зависимости и браузер, из `client/frontend`:
   ```
   npm install
   npx playwright install chromium
   ```
3. Запуск одной командой:
   ```
   npm run e2e
   ```

Отчёт при падении: скриншот и trace лежат в `test-results/`, посмотреть trace — `npx playwright show-trace <путь к trace.zip>`.

## Настройки

| Переменная | По умолчанию | Для чего |
|---|---|---|
| `E2E_URL` | `http://localhost:5173` | адрес фронта |
| `E2E_MOCKS_URL` | `http://localhost:8002` | сервис моков внешних источников; перед каждым прогоном вызывается `POST /mock/reset` (возвращает долг ФНС) |
| `E2E_NO_RESET` | не задана | `1` — не вызывать сброс моков |

## Что важно помнить

- Тесты создают новые заявки и ничего не удаляют. Чистое состояние (`scripts/reset-demo`) нужно только для красоты списка заявок.
- Цели кредита в сценариях подобраны так, чтобы их разбирал словарь, без ИИ. Если словарь целей поменяется и цель
  уйдёт в ИИ, заявка может уйти специалисту, и тест об этом честно упадёт.
- Ставки и суммы записаны по `docs/test-scenarios.md`. При осознанной смене правил скоринга числа меняются в
  `personas.spec.ts` вместе с эталоном и документом.
