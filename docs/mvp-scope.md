# Границы MVP

Что входит в прототип и что нет — по MoSCoW, с обоснованием каждого
исключения. Приоритеты совпадают с метками задач на доске проекта: `P0` —
Must, `P1` — Should, `P2` — Could.

**Граница процесса.** Начало — клиент открывает кабинет и создаёт заявку.
Конец — деньги зачислены (смоделировано), отказ или отмена. В прототип входят
минимальный сквозной путь из ТЗ (подача заявки, приём и проверка, обогащение
данными из внешних источников), скоринг и кредитное решение, а также кабинет
андеррайтера для спорных заявок.

**Тип конвейера** — экспресс-кредитование микро- и малого бизнеса: небольшие
суммы без обязательного залога, решение за минуты, человек подключается
только к спорным заявкам (`day1_backend_domain-research.md`).

## Won't — сознательно не делаем

| Что | Почему |
|---|---|
| **Кредитный комитет** | для экспресс-сумм микро- и малого бизнеса не нужен: решение принимает система или один андеррайтер |
| **Оценка и регистрация залога** | долго и вне цифрового контура. Залог есть только как пятно: клиент его предлагает, андеррайтер проверяет |
| **Реальное подписание электронной подписью и зачисление денег** | ТЗ разрешает моделировать (ограничение 06); реальные операции требуют банковской инфраструктуры |
| **Мониторинг после выдачи** | за границей задачи из ТЗ |
| **Реальные интеграции** с БКИ, ФНС, ЕГРЮЛ, ОФД, маркетплейсами, эквайрингом | запрещены ТЗ (ограничение 04); вместо них локальные моки |
| **Репутационные данные** (отзывы на картах, соцсети, новости) | слабый сигнал, который не может сам привести к отказу; ценность подхода закрывают данные о выручке. Направление развития |
| **Распределение заявок между андеррайтерами и их кредитные полномочия** | зона внутренней системы банка, а не клиентского продукта (см. «Упрощения») |
| **Срок действия одобрения** | не влияет на сквозной путь; в реальном продукте — несколько дней с последующим пересчётом |
| **Уведомления по почте, SMS и в мессенджеры** | запрещены ТЗ (ограничение 05): все события видны в кабинете |
| **Мобильное приложение** | запрещено ТЗ (ограничение 07); только веб-интерфейс |
| **Распознавание документов** | андеррайтер смотрит файл сам; на демо документов единицы. Направление развития |
| **Несколько пользователей одной компании с разными ролями** (собственник, бухгалтер) | в прототипе одна учётка на компанию. Направление развития |

## Упрощения

Упрощения опираются на ограничение 06 ТЗ: допускается упрощённая и явно
описанная логика кредитного решения, подписание и выдача могут быть
смоделированы, внешние сервисы можно воспроизводить в сокращённом виде с
сохранением смысла интеграции.

| Что упрощено | Как в реальном банке | Как в прототипе |
|---|---|---|
| **Андеррайтинг** | заявка, которую нельзя решить автоматически, передаётся во внутреннюю систему банка: там распределяют задачи между сотрудниками и проверяют их кредитные полномочия | эту систему эмулирует кабинет андеррайтера. Лимиты полномочий и данные сотрудников в продукте не храним — это зона внутренней системы банка. Ручная правка условий возможна только с обязательным комментарием, разница условий пишется в журнал |
| **Внешние источники** | БКИ, ЕГРЮЛ, ФНС, ОФД, маркетплейсы и эквайринг по защищённым каналам | локальные моки с сокращённым контрактом: один ИНН — один детерминированный ответ |
| **Скоринг** | статистические модели на исторических данных | балльная модель: вклады факторов и пороги откалиброваны на синтетических персонажах, правила версионируются (`scoring-model.md`) |
| **Подписание и выдача** | электронная подпись, открытие счёта, зачисление | договор по шаблону, кнопка «Подписать», график платежей по аннуитету |
| **Проверка документов** | проверка подлинности и распознавание | андеррайтер принимает или не принимает файл вручную |
| **Согласия клиента** | юридически значимые согласия с подписью | отметка в кабинете; факт согласия хранится в БД |
| **Платёж и срок по кредитам в других банках** | БКИ отдаёт параметры каждого кредита, платёж входит в долговую нагрузку точно | в БКИ-моке есть лимит и остаток, но нет платежа и срока: платёж оценивается условно (аннуитет на остаток за 36 мес. или 5 % остатка для карты и овердрафта, `docs/scoring-model.md`). Кредиты нашего банка учитываются точно, по договору |
