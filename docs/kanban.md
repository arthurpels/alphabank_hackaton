# Канбан: задачи команды

Источник задач для GitHub-доски. Задачи создаются скриптом
`scripts/create_issues.py` (см. раздел «Как залить на GitHub» в конце).

**Роли:** Лид · Б1 (бэкенд: заявка, статусная машина, андеррайтер) ·
Б2 (бэкенд: данные, моки, обогащение, auth) · Ф (фронт) · А (аналитик).
ML-часть (скоринг-движок, аномалии, LLM) — на Лиде: отдельного ML-щика нет,
а скоринг — ядро концепции, его лучше держать у того, кто сводит всё вместе.

**Колонки доски:** Backlog → Todo (на сегодня) → In Progress → Done.
DoD для всех задач: запускается через `docker compose up` + не ломает чужое +
документ/контракт обновлён, если поменялся.

**Приоритеты:** `P0` — без этого нет демо · `P1` — нужно для оценки жюри ·
`P2` — если останется время.

## Как залить на GitHub

Нужен GitHub CLI: `brew install gh`, затем `gh auth login`; для добавления на
доску (Projects) ещё `gh auth refresh -s project`.

```bash
# посмотреть, что будет создано
python3 scripts/create_issues.py --dry-run

# создать метки, вехи и задачи; роли → GitHub-логины, доска — по названию
python3 scripts/create_issues.py \
  --assign lead=arthurpels,b1=LOGIN,b2=LOGIN,front=LOGIN,analyst=LOGIN \
  --project "Кредитный конвейер"
```

Скрипт создаёт задачи и заменяет ссылки `Tnn` в описаниях на номера
GitHub-задач (`#12`), чтобы зависимости были кликабельными.
