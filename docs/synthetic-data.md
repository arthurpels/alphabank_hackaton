## 1. Общие договорённости

- **ИНН проходят проверку контрольной суммы.** Прежние ИНН из
  `external-mocks.md` её не проходили, поэтому у каждого изменены последние
  разряды. Старый `7701234567` теперь служит примером «кривого ИНН» (раздел 9).
- **Один ИНН — один ответ.** Исключение — ФНС после `pay`; состояние
  сбрасывает ручка сброса демо (T18, T21).
- **Источник не заведён для ИНН** → мок отвечает `404`, клиент видит
  «Источник не нашёл данных по вашему ИНН», пятно остаётся открытым.
- **Ряды выручки** — последние 6 или 12 полных месяцев до даты демо:
  октябрь 2025 – сентябрь 2026.
- **Подтверждённая выручка** = среднемесячное значение из подключённого
  источника: ОФД — `revenue`, маркетплейс — `payout` (не `gmv`), эквайринг —
  `turnover`, договор — сумма / срок.

Какие моки заведены для каждого ИНН:

| Мок | Кофейня | Строитель | WB | Техснаб | Однодневка |
|---|---|---|---|---|---|
| ЕГРЮЛ/ЕГРИП | ✓ | ✓ | ✓ | ✓ | ✓ |
| БКИ | ✓ | ✓ | ✓ | ✓ | ✓ |
| ФНС | ✓ | ✓ | ✓ | ✓ + `pay` | ✓ |
| ОФД | ✓ | 404 | 404 | 404 | 404 |

## 11. Открытые вопросы

1. **Ответ Кофейни про март проверяет система.** Иначе пятно уйдёт
   андеррайтеру и автоодобрения в демо не будет. Предлагаемое правило: падение
   в одном месяце, в следующем выручка восстановилась, приложен документ →
   принято. В `process-model.md` похожий пример опирается на выписку, но мока
   выписки у нас нет. Решить с Б1.
2. **Кто проверяет ответ про цель.** Предложение: правило по словарю
   «продукт → допустимые цели» (оборудование, товар, сырьё…); LLM — опционально
   поверх, без неё работает.
3. **Даты зависят от дня демо.** Расчёт сделан на 23.10.2026. После 15.12.2026
   директор Однодневки перестанет быть «новым», а ряды выручки устареют.
   Варианты: моки считают даты от текущего дня (назначен «38 дней назад») или
   в `.env` фиксируется `DEMO_DATE`. Решить с Б2.
4. **Правило «касса и эквайринг расходятся больше чем на 15 %»** сработает у
   Кофейни ложно: эквайринг — только безналичная часть выручки (~67 % от ОФД).
   Предлагаю считать аномалией только эквайринг больше ОФД. Решить с Лидом (T26).
5. **Несколько источников выручки** — берём максимум, а не сумму: касса и
   эквайринг пересекаются. Подтвердить с Лидом.
6. **При неустранимом стоп-факторе** показываем только красные пятна, без
   вилки и без остальных пятен. Подтвердить с Б1 и Ф.
7. **Мок «Репутация»** не заведён, пока его не взяли (вопрос из
   `external-mocks.md`).
