# alphabank_hackaton

## Проверка детерминизма одной командой

Одинаковые действия должны давать одинаковый результат: та же вилка, то же решение, тот же снимок.
Скрипт это проверяет на поднятом стенде (`docker compose up`):

```bash
scripts/check-determinism
```

Что делает:

1. сбрасывает демо-данные (`scripts/reset-demo`) и прогоняет Postman-коллекцию
   `docs/credit-pipeline.postman_collection.json` через newman — все сценарии пяти персонажей из
   `docs/test-scenarios.md`, негативные проверки и папку «ML · детерминизм» (каждый запрос к `ml/` дважды,
   ответ обязан совпасть байт в байт);
2. ещё раз сбрасывает демо, **перезапускает `ml`** и прогоняет коллекцию снова;
3. сравнивает ответы двух прогонов (`scripts/determinism_compare.py`), не учитывая только то, что обязано
   меняться: идентификаторы и время. В конце каждого сценария коллекция вызывает
   `POST /applications/{id}/fork/verify` — пересчёт последнего снимка вилки должен совпасть с сохранённым.

Итог — таблица по сценариям (статус, решение, путь вилки, хеш входа скоринга, `verify`) и список
расхождений. Код выхода 0 — расхождений нет и все проверки коллекции прошли. Отчёты newman и логи —
во временной папке, путь печатается в конце (свою папку можно задать через `DETERMINISM_OUT`).

Нужно: Docker, Node.js (newman запускается через `npx`, версия зафиксирована в скрипте), Python 3.9+.
**Скрипт стирает демо-заявки** — не запускайте его во время показа.
